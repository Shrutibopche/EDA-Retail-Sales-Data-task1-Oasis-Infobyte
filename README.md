# Retail Sales Data Analysis Using Python

## Project Overview

This project focuses on analyzing retail sales data using Python to identify sales trends, understand customer purchasing patterns, and explore product category performance.

The analysis involves data cleaning, exploratory data analysis (EDA), and data visualization to transform raw sales data into meaningful insights that can support business decision-making.

## Objectives

* Clean and prepare the retail sales dataset for analysis.
* Analyze sales trends over time.
* Understand customer demographics and purchasing behavior.
* Identify high-performing product categories.
* Explore relationships between numerical variables.
* Generate insights that can support retail business decisions.

## Dataset

**Dataset:** Retail Sales Dataset
**Source:** Kaggle

The dataset includes information about retail transactions, customer demographics, product categories, quantities purchased, prices, and total transaction amounts.

The analysis uses columns such as:

* Transaction ID
* Date
* Customer ID
* Gender
* Age
* Product Category
* Quantity
* Price per Unit
* Total Amount

## Project Workflow

### 1. Data Loading

Imported the retail sales dataset into a Pandas DataFrame for inspection and analysis.

### 2. Data Inspection

Examined the dataset's dimensions, column names, data types, missing values, and duplicate records.

### 3. Data Cleaning

Prepared the dataset for analysis by checking missing values, identifying duplicate records, reviewing data types, and addressing data quality issues where necessary.

### 4. Exploratory Data Analysis (EDA)

Performed exploratory analysis to understand the dataset and identify patterns in retail sales.

The analysis included:

* Overall sales distribution.
* Monthly and quarterly sales trends.
* Sales by product category.
* Customer distribution by gender.
* Customer age distribution.
* Sales patterns across different days of the week.
* Relationships between numerical variables.

### 5. Data Visualization

Created visualizations using Matplotlib and Seaborn to communicate findings clearly.

Visualizations included:

* Bar charts for product category comparisons.
* Line charts for sales trends over time.
* Histograms for age and sales distributions.
* Count plots for customer demographics.
* Correlation heatmaps for numerical variables.

### 6. Business Insights

Used the visualizations to explore sales performance, customer purchasing patterns, and differences across product categories and time periods.

## Key Learnings

* Cleaning and preparing retail data using Pandas.
* Performing exploratory data analysis on transactional data.
* Working with dates to analyze sales trends.
* Using charts to identify patterns and compare categories.
* Analyzing customer demographics and purchasing behavior.
* Communicating data-driven observations through visualizations.
